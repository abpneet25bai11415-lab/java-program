# Typing Speed Test

A simple Java program that tests your typing speed and accuracy.

## About the Project

This project displays a sentence and asks the user to type it as quickly and accurately as possible. The program measures the time taken and calculates the typing speed in **Words Per Minute (WPM)** along with the typing accuracy.

## Features

* Simple console-based program
* Measures typing time
* Calculates typing speed (WPM)
* Calculates typing accuracy
* Counts correct characters
* Easy to use

## Technologies Used

* Java
* Java Scanner
* System.currentTimeMillis()

## How to Run

1. Make sure Java is installed on your computer.
2. Open the project in VS Code, IntelliJ IDEA, Eclipse, or any Java IDE.
3. Compile the program:

```bash
javac TypingSpeedTest.java
```

4. Run the program:

```bash
java TypingSpeedTest
```

## Example

```text
===== TYPING SPEED TEST =====

Type the following sentence:

Java is a powerful programming language.

Press ENTER when you are ready...

Start typing:
Java is a powerful programming language.

===== RESULTS =====
Time Taken : 8.42 seconds
Typing Speed: 42.76 WPM
Accuracy    : 100.00%
```

## WPM Formula

```text
WPM = (Number of Words / Time in Seconds) × 60
```

## Accuracy Formula

```text
Accuracy = (Correct Characters / Total Characters) × 100
```
